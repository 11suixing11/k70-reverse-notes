## 排障时先区分是哪一层

| 现象 | 本次原因或检查点 | 有效处理 |
| --- | --- | --- |
| ADB `unauthorized` | 手机授权需重新确认 | 手机允许 USB 调试，监视等待授权 |
| 手机 USB 断线 | 枚举、ADB 与反向通道可能分别掉线 | 检查目标设备，按归属恢复通道 |
| 网页能打开，天气不更新 | Breezy USB-only VPN 联网判定 | 查看时间与网络条件，网页补充；保留限制记录 |
| 早期 Java Hook 崩溃 | Android 17 / ART 注入时机 | 优先 attach，延迟仅按自制样本验证 |
| “装了 Ghidra”却没有 GUI | 实际配置的是 headless | 使用 headless 分析，明确 GUI 未配置 |
| x86 ELF 不能原生执行 | ARM64 CPU、加载器与库条件 | 静态分析；QEMU 单独验证 |
| PE 能反编译但不能运行 | 还需要 Windows API/环境 | 动态调试交给 Windows 电脑 |
| 图标包套不上 | 当前 Trebuchet 不支持 | 使用实测支持图标包的 Lawnchair |
| 微件空白/消失 | host 归属或网格迁移改变绑定 | 重新绑定，核对 provider 与 callbacks |
| DB 改了界面没变 | HOME 自动重启、旧内存布局 | 先打开设置，再停止 HOME 并确认退出 |
| 自动亮度最终没开 | 调试时临时设置未恢复 | 收尾读回并重启复查 |

## 怎样避免夸大验证

安装成功、版本命令成功、真实功能成功和长期稳定是不同的层次。我们增加了断点、Hook、反编译、导出与手势检查，仍只把结论限定在测试覆盖范围。

声音比较也有范围：Root 前后持久音量与振铃模式一致，assistant stream 的瞬时 mute 标志曾变化，音量仍为 0；这不是已修改用户声音设置。本轮主题阶段持久化音量与提示音比较差异为空。

工具升级以后，用自己的样本再测一轮即可发现依赖和时机问题。无需每次重刷系统，也不应为了单个工具直接引入未知内核模块。
